Architecture · runs on one laptop

AI News Agent

A daily digest of the most important AI news, scored and summarised by Qwen3.5-4B running locally in Ollama. No cloud model, no GPU.

i7-8650U · 4 cores 16 GB RAM · no GPU Qwen3.5-4B Q4_K_M · 3.4 GB daily 07:00 · ~24 min Telegram · Gmail · WhatsApp

The model writes about 5 tokens a second on this CPU, so writing the output is the cost. Lowering max_triage or top_n in config.yaml is the quickest way to shorten a run.

Why it's built this way

Code narrows, the model judges

Filtering by date, keywords and history is free. The model only reads items that already look promising.

One small job per call

A 4B model scores one item, answers one yes/no or summarises one article at a time. JSON schemas keep its answers parseable.

Summaries stay grounded

The model sees only the article text and is told not to add outside knowledge. Every story links to its source.

Failures are skipped, not fatal

A dead feed, a blocked article, a bad JSON reply or an unconfigured channel is logged, and the digest still goes out.
